# PlanIt – AI-Powered Travel Planning Application

## Overview

PlanIt is an AI-powered travel planning application designed to simplify trip organization by providing personalized travel recommendations, itinerary generation, and destination management. The platform enables users to plan, organize, and track their trips through an intuitive and user-friendly interface.

## Features

* User Authentication and Account Management
* AI-Powered Travel Recommendations
* Personalized Trip Itinerary Generation
* Destination Search and Exploration
* Trip History Management
* Interactive and Responsive User Interface
* Secure Cloud-Based Data Storage
* Real-Time Travel Information Integration

## How It Works

1. User creates an account or logs in.
2. User enters travel preferences and destination details.
3. Gemini AI analyzes the input.
4. The system generates a personalized travel itinerary.
5. Trip information is saved in Firestore.
6. Users can access and manage previous travel plans.
